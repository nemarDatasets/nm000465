DATA & FILE OVERVIEW

1. Folder List (more information about the format and contents of files can be found in the DATA-SPECIFIC INFO section below): 
	A. data.zip. This folder contains raw local field potential data from the Neuralynx recording system. Subfolders 	"main" and "localizers" contain the recordings from subcortex and cortex during the main task and from cortex during 	the localizer task, respectively. There is one file for each participant.
	B. behav.zip. This folder contains the behavioral metrics (accuracy, RT) and trial conditions from the behavioral 
	task, contained in Audiostop.zip. 
	C. pp.zip. This folder contains preprocessed LFP data in EEGLab format. 
	D. beta.zip. This folder contains the timing of beta bursts within the data. 
	E. functions.zip. This folder contains support functions for the analysis code.
	F. Audiostop.zip. This folder includes MATLAB code for the behavioral task participants performed.
Main analysis functions StopOR_initialize.m, StopOR_preprocess.m, and StopOR_betaev.m were used to initialize folder trees, preprocess the LFP data, and perform the main analyses, respectively. Required support functions (excluding the EEGLab and Fieldtrip toolbox) are included in the functions.zip folder. Please see the extensive comments within those MATLAB scripts for more information on how the analyses are performed. 


2. Relationship between files, if important: 
The files containing behavioral information on each task trial in the "behav" folder are incorporated with electrophysiological data when the files in the "data" folder are loaded. Information from each trial is added to every event trigger in the LFP file so that it can be easily referenced. These preprocessed LFP files with behavioral information added are stored in the "pp" folder, and are the files used to create the indices of beta bursts (stored in the "beta" folder). 


METHODOLOGICAL INFORMATION

1. Description of methods used for collection/generation of data: 
Briefly, local field potentials were gathered from the sensorimotor cortex and either the STN or thalamus of patients undergoing deep brain stimulator implantation surgery. Following placement of sensorimotor leads, participants performed a short, two-choice response task (a localizer) while we recorded from subcortical leads to confirm correct placement of electrodes. Later, once subcortical leads were placed, they performed a stop-signal task while we recorded from cortical and subcortical leads. Event markers for both tasks were logged using TTL pulses from a USB DAQ device to an input channel.
A full description of the data collection procedure and hardware used can be found in the Methods section of the published eLife manuscript at DOI: 10.7554/eLife.70270.

2. Methods for processing the data: 
Preprocessing - 
Raw LFP data from the Neuralynx recording system were loaded into MATLAB, filtered for line and high-frequency noise, and converted into EEGLab standard format. Relevant behavioral information was added to the event marker structures. 
Analyses - 
Using the preprocessed LFP data, we filtered the data to look specifically at activity in the beta band (15-29Hz) and converted the data surrounding event markers of interest to the time-frequency domain using the complex Morlet wavelet method. Periods of time in which the amplitude envelope exceeded 6 times the median amplitude for at least two beta cycles were quantified as beta bursts. Indices of the beta events were saved and used in further analyses performed by the included scripts (for example, looking at rates of stimulus-locked bursts following events of interest or assessing beta burst rates in sensorimotor cortex following bursts in subcortex).
For additional details about preprocessing and analysis, please refer to the Methods section of the published eLife manuscript at DOI: 10.7554/eLife.70270.

DATA-SPECIFIC INFORMATION FOR FILES IN DATA.ZIP (both localizer and main folders)
Each file is a .mat file of the naming convention Subject_XXX, with the XXX as a three-digit subject identifier. These files were generated from the Neuralynx recording system. Within each .mat file, the digitized data is stored separately for each channel, with the naming convention LFPx_RZ2_chan0XX. Triggers are represented as up-flanks (from TTL pulses) in an input channel, saved as Inpt_RZ2_chn_0XX. Within these channel data structures, the data itself is saved in a field called "dat", where each row is the voltage at a digitized timepoint at the recording frequency. Correspondence of channel numbers to anatomical locations varies by subject - the location names of the channels are listed in and implemented by the scripts getchans.m and getlocchans.m in the functions folder. Scripts to load in the Neuralynx formatted data to MATLAB and convert to EEGLab format are also included in the functions folder and called within StopOR_preprocessing.m.

Definitions of variables within the directory "data":
(Each .mat file in the subfolders "main" and "localizers" contain outputs from the Neuralynx recording system. The following variables were used in analysis:)
- Structures of the name format Inpt_RZ2_chn00X and LFPx_RZ2_chn_0XX: Structures containing the recording data and info about the recording. Subfields of interest:
	- dat: a vector of MATLAB singles that is samplepoints x 1.
	- chan: the index of the channel
	- block: the recording block (a unique participant id and block #
	- code: a string, either 'Inpt' for input channels or 'LFPx' for data channels

DATA-SPECIFIC INFORMATION FOR FILES IN BEHAV.ZIP
Behavioral data is stored in .mat files in the behav.zip folder. Behavioral data for localizers is in a subfolder, called "localizers". All files have the naming convention Subject_XXX.mat, where XXX is a three-digit identifier that matches the participant's LFP data. Within these .mat files, the data is saved in a variable named trialseq, which has the dimensions trials x 10. Correspondence of the 10 columns to variable types (i.e., response accuracy, the trial conditions) is specified in functions/Basicstop_columns.m.

Definitions of variables within the directory "behav":
Behavioral data produced by the task code is stored in the base folder for main task runs and in the "localizers" subfolder for localizer runs. Participants 104 and 116 have additional blocks, stored in the subfolders "104 go only" and "116 extra". These files have the format Subject_XXX.mat. Each .mat file contains the following variables:
- data: a structure created by task code to store participant info, including Nr, an arbitrary identifier, and EEG, the setting for sending TTL triggers to the recording. Note that fields age, gender, and hand are optional based on the task but have been left empty to protect patient privacy.
- settings: a structure containing information about the task code settings at the time of the experiment. The input field lists starting SSD, trial numbers for each condition, and number of blocks. The eeg field lists the USB port name and marker unit. The files field lists the output folder and file name. The duration field lists the response deadline, trial length, max SSD, and SSD adjustment increment. The sound field lists the sampling rate of auditory stimuli, the number of sound channels, audio handle settings, and the frequency and duration of stop and go stimuli.
-trialseq: A trials x 10 matrix storing trial setting codes and behavioral data. The column labels and codes can be found in functions/Basicstop_columns.m.
Also in the "behav" folder is the "excluded subfolder, which contains .mat files with the same variables as specified above for participants not included in analyses based on exclusion criteria.
The "ssrt" folder contains files of the name convention SubjectXXXssrt.mat. 
- Each file has the structure SSRTdata, containing fields created using the functions/SSRT.m script. The subfields are estimations of participant SSRT using different methods (I.e., the integration method, mean method, etc.). 
The subfolder "out" contains files named SubjectXXX_behavanalysis.mat.
- Each file contains a structure named "behav", which are behavioral metrics for each subject created with functions/Basicstop_analyze.m. Subfields are numbers (the number of trials per specified condition), rates (the accuracy of specified conditions), and RT (mean reaction times in ms per specified condition).

DATA-SPECIFIC INFORMATION FOR FILES IN PP.ZIP
Preprocessed LFP data in EEGLab format is stored in the pp folder, with naming convention SubjectXXX-LFP.mat, with a three-digit identifier that matches all other data files for that participant. The contained variable, LFP, which is generated using StopOR_preprocessing.m executed section-by-section, is a MATLAB structure in standard EEGLab format (I.e., data in LFP.data, event markers in LFP.event, etc.), which contains filtered data with relevant behavioral info from trialseq added to LFP.event.

Definitions of variables within the directory "pp":
Preprocessed data files are files named SubjectXXX-LFP.mat (main task run) and SubjectXXX-localizer.mat (localizer run).
- Each file contains a structure named "LFP", which is recording data in EEGLab standard format. For a full definition of the contents of each of the subfields, please see EEGLab documentation at: https://eeglab.org/tutorials/ConceptsGuide/Data_Structures.html. 
Files of the naming convention ManunalRejXXX_localizer.mat (for localizers) and ManualRejXXX.mat (for main task runs) contain the following variables created during manual inspection of the data for artifacts:
- rejections: vector containing indices in seconds of the 1-second segments of the data containing artifacts
- rejpoints: N x 2 matrix of the start and end points of to-be-rejected data segments in sample points

DATA-SPECIFIC INFORMATION FOR FILES IN BETA.ZIP
Following preprocessing, the processed data files included in pp.zip were used to generate beta burst latencies with the script StopOR_betaev.m, producing files stored in beta.zip. These .mat files store several types of information used in analyses, the main being a variable named trialevs, which is a structure that stores channel fields. Within those channel fields are the latency of beta bursts surrounding event markers in fields named t.x (where x is a trial number). The files with the naming convention SubjectXXX.mat have beta bursts from the main channels used in analysis (see the manuscript for details on why these were the channels used). Files SubjectXXX_dorsal.mat and SubjectXXX_allstn.mat contain data from additional channels in thalamus and STN, used for supplementary analyses. 

Definitions of variables in the directory "beta":
Files with names of the format SubjectXXX.mat (containing main STN chans and ventral that info), SubjectXXX_allstn.mat (containing info for dorsal AND ventral STN), and SubjectXXX_dorsal.mat (containing info for dorsal thal) contain information produced by the beta burst analyses:
- trialevs: a structure with subfields for each channel analyzed. Within channel fields, there are subfields for each trial/epoch. Each trial field contains a vector with the time latency in ms of any beta bursts that occurred during that trial. This structure has beta burst latencies that followed the task stimulus.
- blevs: a structure of the same format and subfields as trialevs, but which contains beta burst latencies during the time period BEFORE the task stimulus.
- trialseq: matrix containing behavioral data from the task. This variable explained in more detail above when explaining "behav" folder variables.
- tnum: N x 1 vector of the trial number that corresponds to the epoch fields in trialevs.
- ssd: N x 1 vector of the trial-wise stop signal delay that corresponds to the epoch fields in trialevs.
- side: N x 1 vector of the trial-wise response direction that corresponds to the epoch fields in trialevs.
- rt: N x 1 vector of the trial-wise RT that corresponds to the epoch fields in trialevs.
- accuracy: N x 1 vector of the trial-wise accuracy code that corresponds to the epoch fields in trialevs.
- RT: participant RT in ms
- SSRT: participant SSRT in ms
- chanlabels: cell array of the channels selected for beta analyses.
- selchans: double vector of the indices of channels used in analysis for the following channel locations - [rstn lstn rmotor lmotor rthal lthal]
- LM1: complete recording data from the left motor electrode pair in EEGLab structure format. For a full definition of the contents of each of the subfields, please see EEGLab documentation at: https://eeglab.org/tutorials/ConceptsGuide/Data_Structures.html. 
- RM1: complete recording data from the right motor electrode pair in EEGLab structure format. For a full definition of the contents of each of the subfields, please see EEGLab documentation at: https://eeglab.org/tutorials/ConceptsGuide/Data_Structures.html. 
- LSTN: if STN electrodes present, contains complete recording data from the left STN electrode pair in EEGLab structure format. For a full definition of the contents of each of the subfields, please see EEGLab documentation at: https://eeglab.org/tutorials/ConceptsGuide/Data_Structures.html. 
- RSTN: if STN electrodes present, contains complete recording data from the right STN electrode pair in EEGLab structure format. For a full definition of the contents of each of the subfields, please see EEGLab documentation at: https://eeglab.org/tutorials/ConceptsGuide/Data_Structures.html. 
- LVIM: if thalamic electrodes present, contains complete recording data from the left thalamus electrode pair in EEGLab structure format. For a full definition of the contents of each of the subfields, please see EEGLab documentation at: https://eeglab.org/tutorials/ConceptsGuide/Data_Structures.html. 
- RVIM: if thalamic electrodes present, contains complete recording data from the right thalamus electrode pair in EEGLab structure format. For a full definition of the contents of each of the subfields, please see EEGLab documentation at: https://eeglab.org/tutorials/ConceptsGuide/Data_Structures.html. 
Files with names of the format SubjectXXXselchans.mat contain information about the channels selected for the beta burst analyses.
- chanlabels: cell array of the channels selected for beta analyses.
- selchans: double vector of the indices of channels used in analysis for the following channel locations - [rstn lstn rmotor lmotor rthal lthal]
